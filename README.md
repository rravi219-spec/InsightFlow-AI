# InsightFlow AI

Adaptive business intelligence platform built with Python, Streamlit, FastAPI, SQLAlchemy, Plotly, and machine learning.

## Overview

InsightFlow AI allows users to upload CSV or Excel datasets and automatically generates:

- dataset profiling
- adaptive column mapping
- dynamic KPIs
- interactive visualizations
- churn and customer analysis
- cleaned-data exports
- machine-learning predictions through a FastAPI backend

## Tech Stack

- Python
- Streamlit
- FastAPI
- Pandas
- Plotly
- SQLAlchemy
- SQLite
- Scikit-learn
- Joblib
